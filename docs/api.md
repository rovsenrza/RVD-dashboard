# РВД Кабинет — API

Для того, кто подключает к кабинету ERP, учётную систему или свой скрипт (ТЗ 6: «интеграция с 1С, ERP и другими учётными системами через API»). Кабинет сам работает через этот API — всё, что видно на экране, доступно и здесь, с теми же правами.

Источник правды по данным — 1С поставщика: API отдаёт кэш, который сверяется с 1С каждые 10 минут (`GET /sync`). Изменить в 1С через API можно только то, что может клиент в кабинете: заявки, внутренний №, место установки, подразделение техники, комментарии и файлы.

## Общее

- Адрес — `PUBLIC_API_PATH` сервера (например, `https://api.clientrvd.vgiz.ru`). Тела и ответы — JSON в UTF-8, даты — `YYYY-MM-DD`, моменты — ISO 8601.
- Ошибка — код и `{ "message": "…" }` по-русски, текст можно показывать человеку: `400`/`422` — неверные данные, `401` — нужен вход, `403` — не хватает роли, `404` — нет такого или чужое (чужие данные неотличимы от несуществующих), `429` — слишком много попыток входа, заголовок `Retry-After`.
- Типы ответов — в [`packages/contracts/src/types.ts`](../packages/contracts/src/types.ts) (`Product`, `Equipment`, `ServiceRequest`, `Replacement`, `DashboardSummary`, …), проверки входных данных — там же (`requestProblem`, `settingsProblem`, `equipmentProblem`, …): сервер и форма кабинета проверяют одним кодом.

## Вход

1. `POST /auth/login` `{ "email", "password" }` → `{ accessToken, user, company, branches, mustChangePassword }` и cookie обновления (httpOnly).
2. Дальше каждый запрос — с заголовком `Authorization: Bearer <accessToken>`. Пропуск живёт 15 минут; `POST /auth/refresh` (с cookie) выдаёт новый, `POST /auth/logout` гасит сессию.
3. Скрипту без cookie проще войти заново, когда пришёл `401`.

Для интеграции администратор компании заводит отдельного пользователя с нужной ролью — его действия так же попадут в журнал. Пока `mustChangePassword` — открыты только `/me` и `POST /auth/password`.

Каждый запрос видит только данные своей компании. Компания — один или несколько клиентов в 1С, её филиалы (`branches`: `id` — Клиент_Key, `name`); человек видит свои филиалы — названные администратором или все. Параметр `?branch=<id>` у списков сужает до одного своего филиала, чужой — не сужает и ничего не открывает. Заявка — заказ одного филиала: её изделия должны быть из одного, без изделий филиал называет `branchId`. Роли: **механик**, **инженер** — изделия, техника, заявки, уведомления; **руководитель** — плюс отчёты и сравнение; **администратор** — плюс пользователи, настройки, журнал и синхронизация.

## Маршруты

### Вход и профиль

| Метод | Путь             | Что делает                                                                |
| ----- | ---------------- | ------------------------------------------------------------------------- |
| POST  | `/auth/login`    | Вход, см. выше. 5 неудачных попыток на учётную запись за 15 минут — `429` |
| POST  | `/auth/refresh`  | Новый пропуск по cookie                                                   |
| POST  | `/auth/logout`   | Выход                                                                     |
| POST  | `/auth/password` | Смена своего пароля `{ current, next }`; остальные сессии гаснут          |
| GET   | `/auth/invite`   | `?token=` — чьё приглашение (из письма), без входа                        |
| POST  | `/auth/invite`   | `{ token, password }` — задать пароль по приглашению и войти              |
| GET   | `/me`            | Кто вошёл                                                                 |
| GET   | `/health`        | Жив ли сервер, база и синхронизация — для мониторинга, без входа          |

### Изделия (РВД)

| Метод | Путь                          | Что делает                                                                                                                                                                                                                                    |
| ----- | ----------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| GET   | `/products`                   | Реестр страницами: `page`, `limit` (до 5000), `sort`, `dir`, `q` (номер EHS, внутренний, каталожный, гаражный, место), `status`, `lifecycle`, `equipment`, `catalog`, `installed`, `archive`. Ответ — `{ items, total, page, limit, counts }` |
| GET   | `/products/:id`               | Карточка изделия                                                                                                                                                                                                                              |
| PATCH | `/products/:id`               | `clientNumber`, `equipmentId`, `installPlace` — то, что ведёт клиент; дату установки ведёт поставщик                                                                                                                                          |
| GET   | `/products/:id/lifetime`      | Фазы срока службы: гарантия, «Внимание», плановая замена                                                                                                                                                                                      |
| GET   | `/products/:id/history`       | История жизненного цикла из 1С                                                                                                                                                                                                                |
| GET   | `/products/:id/replacements`  | Замены, где изделие сняли или поставили                                                                                                                                                                                                       |
| GET   | `/products/:id/documentation` | Техническая документация по каталожному номеру                                                                                                                                                                                                |
| GET   | `/products/:id/comments`      | Комментарии специалистов; `POST` — добавить `{ text }`                                                                                                                                                                                        |
| PATCH | `/comments/:id`               | Исправить свой комментарий; `DELETE` — удалить (автор или администратор)                                                                                                                                                                      |
| GET   | `/products/:id/attachments`   | Фото и документы изделия                                                                                                                                                                                                                      |
| GET   | `/catalog-numbers`            | Каталожные номера (OEM) из 1С                                                                                                                                                                                                                 |

### Техника и замены

| Метод | Путь                          | Что делает                                                          |
| ----- | ----------------------------- | ------------------------------------------------------------------- |
| GET   | `/equipment`                  | Техника компании со счётчиками РВД по состоянию и ближайшей заменой |
| GET   | `/equipment/:id`              | Карточка машины                                                     |
| PATCH | `/equipment/:id`              | Подразделение и заводской № (то, что ведёт клиент)                  |
| GET   | `/equipment/:id/products`     | РВД на машине                                                       |
| GET   | `/equipment/:id/replacements` | Замены на машине                                                    |
| GET   | `/replacements`               | Журнал замен, новые первыми                                         |

### Главная, отчёты, сравнение

| Метод | Путь                 | Что делает                                                                                                                                                                 |
| ----- | -------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| GET   | `/dashboard/summary` | Показатели главной; `days` = 30, 90 или 365 — период изменений и замен                                                                                                     |
| GET   | `/reports/:id`       | Отчёт: `registry`, `warranty`, `due`, `plan`, `replacements`, `equipment`, `branches`; `from`, `to` — период. Руководитель и администратор. Ответ — колонки, строки, итоги |
| GET   | `/analytics/models`  | Сравнение моделей техники. Руководитель и администратор                                                                                                                    |

### Заявки и файлы

| Метод  | Путь                        | Что делает                                                                                                                                                                      |
| ------ | --------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| GET    | `/requests`                 | Заявки компании со статусом в 1С и доставки                                                                                                                                     |
| POST   | `/requests`                 | Новая заявка `{ branchId, kind: "replace" \| "manufacture" \| "repair", positions, comment, attachmentIds }`. Уходит в 1С из очереди: пока 1С не приняла — `delivery: "queued"` |
| POST   | `/attachments`              | Загрузить файл (multipart, JPG/PNG/WebP/PDF/Word/Excel, до 10 МБ, проверка антивирусом) → `Attachment`; id передаётся в заявку или на изделие                                   |
| DELETE | `/attachments/:id`          | Удалить файл                                                                                                                                                                    |
| GET    | `/attachments/:id/:variant` | Сам файл или миниатюра по подписанной ссылке из `Attachment.url` (ссылка живёт до двух часов)                                                                                   |
| POST   | `/support/messages`         | «Связаться со специалистом» `{ topic, text, productId?, installedAt? }`                                                                                                         |

### Уведомления

| Метод | Путь                     | Что делает                                                    |
| ----- | ------------------------ | ------------------------------------------------------------- |
| GET   | `/notifications`         | Уведомления за 30 дней, новые первыми, с отметкой «прочитано» |
| POST  | `/notifications/read`    | `{ ids }` — прочитать эти, без тела — все                     |
| GET   | `/me/notification-prefs` | Какие правила и письма человек получает; `PATCH` — изменить   |

### Администрирование (администратор компании)

| Метод | Путь                              | Что делает                                                                                    |
| ----- | --------------------------------- | --------------------------------------------------------------------------------------------- |
| GET   | `/admin/users`                    | Пользователи компании; `POST` — добавить (ответ с одноразовым паролем или письмо-приглашение) |
| PATCH | `/admin/users/:id`                | `name`, `email`, `role`, `branchIds` (пусто — вся компания; механику — ровно один), `active`  |
| GET   | `/admin/branches`                 | Филиалы компании (клиенты в 1С): техника, РВД в работе, пользователи                          |
| POST  | `/admin/users/:id/reset-password` | Сбросить пароль                                                                               |
| GET   | `/admin/settings`                 | Настройки компании: «Внимание», сроки уведомлений, осмотр, письма; `PATCH` — изменить         |
| GET   | `/admin/audit`                    | Журнал действий                                                                               |
| POST  | `/sync`                           | Сверить с 1С сейчас                                                                           |
| GET   | `/sync`                           | Когда кэш последний раз совпал с 1С и отвечает ли 1С (доступно всем)                          |
| GET   | `/sync/status`                    | По каждой таблице кэша: когда, сколько строк, сколько длилось                                 |

## Пример

```sh
API=https://api.clientrvd.vgiz.ru
TOKEN=$(curl -s -X POST $API/auth/login -H 'Content-Type: application/json' \
  -d '{"email":"erp@company.ru","password":"…"}' | jq -r .accessToken)
# Все РВД, требующие замены, одним списком
curl -s "$API/products?status=replace&limit=5000" -H "Authorization: Bearer $TOKEN" | jq '.items[] | {serialNumber, catalogNumber, equipmentId}'
```
