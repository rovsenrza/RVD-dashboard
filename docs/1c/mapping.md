## Главное открытие: даты и статус берутся из документов «Выпуск»

В `Catalog_Изделия` нет ни даты отгрузки, ни даты установки, ни техники. Всё это — в **`Document_Выпуск`** (8 595 документов, 3 689 изделий): каждая смена статуса изделия — отдельный документ со ссылкой на изделие и на технику.

Статусы документа (`Статус`): `НаОформлении`, `Изготавливается`, `НаСкладе`, `Отгружен`, `ВЭксплуатации`, пустой (1 025). Типичные цепочки: `Изготавливается → НаСкладе → Отгружен` (953), одиночный `НаОформлении` (718), `НаСкладе, НаСкладе` (708), `ВЭксплуатации` (184).

`Document_ЗаказыКлиента.СозданВРВД` (у всех 1 666 сейчас `false`) — признак «создан в базе РВД», а не в УТ; это **не** «создан кабинетом», как мы сперва думали (разработчик 1С, 2026-10-03). Для заказов из кабинета он предлагает заменить флаг перечислением-источником «РВД / внешний / УТ» или добавить признак «внешняя / внутренняя»; по нему кабинет и будет отбирать свои заказы.

Заявка кабинета → «Заказ клиента» (Д18, ответы заказчика 2026-10-03): строка «Замены» — `Изделие_Key` заменяемого изделия + его `КаталожныйНомер_Key` и `Техника_Key` (техника у каждой строки своя — 1С это позволяет); строка «Изготовления» / «Ремонта» — `КаталожныйНомер_Key`, а номер не из справочника — текстом. Реквизита для типа заявки (замена / изготовление / ремонт) в документе нет, как нет и поля под номер текстом и места для файла Excel заявки без строк — вопрос 16 разработчику 1С.

## Статусы заявки

`СтатусЗаказа` → наш `RequestStatus`: `Черновик`/`КВыполнению` → «Новая», `ВРаботе` → «В работе», `Выполнен` → «Выполнена». Отказ («Отклонена») в данных не встречается — нужен ответ, как 1С помечает отклонённый заказ.

## Риски и вопросы

1. **«Филиал» в 1С — это филиалы поставщика**, а не подразделения клиента. У `Catalog_Клиенты` один `Филиал_Key` на клиента (6 филиалов на 312 клиентов; в выборке из 20 клиентов встретилось всего три значения). Кабинетная модель «Компания → Филиал» для клиента с несколькими площадками ложится на **несколько записей `Клиенты`** (пример из демонстрации: «КСТ УАТ», «УРГО») или на ещё не найденный реквизит. Нужно уточнить у разработчика, иначе выбор филиала в шапке не на чем строить.
2. **Каталожный номер заполнен у 14 % изделий.** У остальных тип виден только по наименованию. Предложить заполнить на стороне 1С; до этого колонка будет часто пустой, а состав и сроки берём с самого изделия.
3. **Статус `Списан` не встречается** — архив в кабинете пока пуст; ждём, как 1С списывает изделие.
4. **Порядок документов.** Внутри одной секунды у `Выпуск` бывают равные даты; последний документ выбираем по `Date`, затем по `Number`.
5. **Два недоступных объекта** (`Модели`, `ВыпускЗаСмену`) — запросить публикацию.
6. **Запись в 1С.** Доступ только на чтение. Для заявок и замен нужны права на запись документа «Заказ клиента» (или HTTP-сервис) — вопрос 2.
